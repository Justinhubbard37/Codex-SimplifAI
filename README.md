# SimplifAI

SimplifAI is a desktop-first AI application designed to turn complex source material into usable outputs such as step-by-step guides, summaries, concept explanations, and training outlines.

## Primary Build Direction
- **App Type:** Tauri v2 desktop application
- **Frontend:** React + TypeScript
- **Desktop Shell:** Rust via Tauri
- **Approach:** Desktop-first, modular, and local-first by default

## Repository Purpose
This repository contains the source code, product spec, and implementation plan for SimplifAI.

## Key Project Files
- `AGENTS.md` — repository rules and build instructions for Codex
- `docs/simplifai-spec.md` — product specification
- `plans/build-plan.md` — implementation roadmap

## Current Status
Initial project setup and planning repository for a fresh build.

## High-Level Product Goal
SimplifAI is intended to help users convert complex, jargon-heavy, or multi-format source content into clearer, more usable outputs with a strong focus on practical understanding and actionable guidance.

## Intended Stack
- Tauri v2
- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- Mermaid.js or equivalent

## Notes
This project should be treated as a **desktop application first**, not as a standard browser-only web app.
